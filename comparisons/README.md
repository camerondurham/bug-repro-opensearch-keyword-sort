# Local comparison results

This directory contains machine-specific generated comparisons of three local five-release matrices
against the unchanged GitHub Actions reference. Keep one output directory per machine; compare each
machine separately using the generated reports. See the main [README](../README.md) for workload,
safety checks, and historical observations.

## Prerequisites and protocol

Read the main README's [local reproduction prerequisites](../README.md#run-one-release-with-the-published-protocol)
first. Use a quiet Linux x86-64 host meeting its Docker, Python, resource, and sysctl requirements,
with Git installed and a clean tracked checkout; unrelated untracked work is left alone. The wrapper does not configure
the sysctl. It records basic CPU, OS, memory, timestamps, and source commit in `host.json`, without
private hostname, user, or IP data. GitHub credentials and GitHub environment variables are not needed.

The fixed protocol runs three matrices of all five releases (15 release invocations) in the existing
varied orders, with no retries and a 780-second cap per release. The three matrices can take up to
195 minutes plus reporting; a prior run took about 28 minutes, which is not a runtime guarantee. Each
machine's three local matrices are compared with the unchanged Actions reference. Valid no-speedup
results are publishable evidence.

## Run the wrapper

Choose a machine-specific directory:

```bash
python3 run_comparison.py --output comparisons/ryzen-wsl2
```

To rerun this machine and replace its previous results:

```bash
python3 run_comparison.py --output comparisons/ryzen-wsl2 --replace
```

A different machine can use its own directory:

```bash
python3 run_comparison.py --output comparisons/x86-vm
```

An existing output without `--replace` fails before any workload. `--replace` accepts only a directory
previously generated by this wrapper, identified by its `host.json` generator marker; it is not a
general-purpose directory delete. The runner stages in a temporary sibling and keeps the previous
output until full validation succeeds. Failed or incomplete batches leave the previous output
unchanged, retain temporary evidence, and print its location.

A successful output contains `summary.md`, `ratios.svg`, `latency.svg`, `report.html`, `comparison.json`,
`host.json`, and `datasets/{local-1,local-2,local-3,actions}/` with raw and reporter results. Commit
the entire output directory, including raw evidence. Separate machine directories stay separate, and
previous committed results remain in Git history. There is no automatic commit, upload, machine
registry, or extra manifest.

## Offline re-rendering

Redraw from retained raw inputs without Docker or network:

```bash
python3 report.py --compare \
  local-1=comparisons/ryzen-wsl2/datasets/local-1/raw \
  local-2=comparisons/ryzen-wsl2/datasets/local-2/raw \
  local-3=comparisons/ryzen-wsl2/datasets/local-3/raw \
  --reference actions=comparisons/ryzen-wsl2/datasets/actions/raw \
  --output local-report/comparison
```

This writes an untracked report outside the committed comparison. Do not change raw inputs or pool
matrices. Whole-matrix equality checks, source validation, and report validity remain distinct safety
checks.

## Contribute a result

Inspect the report, `host.json` provenance, and the `comparison.json` `valid` field. Stage only the
chosen machine directory:

```bash
git add -- comparisons/ryzen-wsl2
git diff --cached --stat
```

Review the complete staged diff, including raw files, then commit and open a PR with the results. The
wrapper never commits or pushes for you. The original local investigation remains available through the
frozen commit linked from the main README.
